# MakeMeViral — Product Requirements (Corrected)

## Business model

**Paid discovery / paid listing platform.**

Users and businesses pay for:
1. **Listing placement / visibility** (Standard, Top 50/20/10, Featured, Homepage)
2. **Profile capacity** (Free 50 listings → Creator/Business/Pro upgrades)

This is NOT a voting, popularity, or engagement-ranking product.

## Non-negotiable

Placement is determined by:
- paid promotion slots
- admin curation (including Trending)
- publish order for standard listings

Placement is NEVER determined by likes, views, saves, shares, or engagement scores.

Analytics may be collected for reporting only.

## Trending

Trending = paid placements + featured + admin-curated listings + newly promoted content.
Not “most liked” or “most viewed.”

## Monetization

### A — Promote a listing
User pays for a time-limited slot (Top 10/20/50, Featured, Homepage).

### B — Upgrade profile
User pays for a higher listing limit (50 → 100 → 500 → 1000+). Configurable in admin.
